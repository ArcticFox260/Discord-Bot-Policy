Fox Management — Privacy Policy

Effective Date: 10 February 2026

Bot Owner: Arctic

1. Information Fox Management Collects

Fox Management collects and stores the following information when moderation actions occur:

  • Discord User ID of the member being actioned
  • Discord User ID of the moderator performing the action
  • Action type (e.g., Warn, Ban, Kick, Timeout)
  • Reason for the action (if provided)
  • Timestamp of the action
  • Additional context depending on the command (e.g., duration for timeouts)
  • Server/Guild ID where the action occurred
  • Message content (only when a message is deleted by moderation)
  • Channel information (for channel-related actions)
  • Role information (for role-related actions)
  • Voice channel activity logs (joins, moves, disconnections)
  • Movie voting data (submissions, votes, usernames)
⚠️ Important: Fox Management stores moderation logs including message content for deleted messages. Users should be aware that moderation actions and their context are permanently recorded.

2. Purpose of Data Collection

Fox Management stores this information to:

  • Maintain accurate moderation history and audit trails
  • Allow moderators to review past actions and disputes
  • Support appeals and provide evidence for moderation decisions
  • Improve server safety and accountability
  • Document server administrative changes (channels, roles, settings)
  • Track temporary voice channel usage
  • Manage movie voting sessions

This data is not used for:

  • Advertising or marketing
  • Analytics sold to third parties
  • Profiling or targeted content
  • Any purpose beyond server moderation and management

3. Data Retention

Moderation logs are stored indefinitely unless:

  • Manually deleted by the server owner
  • A user requests removal (see Section 6)
  • Discord requires deletion per TOS violation
  • The server is deleted

Historical note: Audit logs older than 90 days may be automatically pruned depending on database maintenance.

4. Who Can Access the Data

Access to stored data is limited to:

  • The server owner and designated administrators
  • Fox Management bot itself (for lookups, logging, and appeals processing)
  • The affected user (via appeals system, if applicable)

No data is shared with:

  • Third-party services or analytics providers
  • Discord (except as required by their TOS)
  • Any external parties without explicit consent

5. How the Data Is Stored

Data is stored in a private MongoDB database controlled by the server owner. Security measures include:

  • Restricted database access (connection strings stored in environment variables)
  • TLS/SSL encryption for database connections
  • Access limited to bot and authorized administrators only
  • No public endpoints or API exposure

Important: The server owner is responsible for securing their database credentials and access logs.

6. Appeals and User Data

Fox Management includes an appeals system that allows users to:

  • Submit appeals for moderation actions via DM
  • View their appeal status
  • Request review by server moderators

Appeal data is stored separately and includes:

  • User ID and appeal message content
  • Appeal status (pending, approved, rejected)
  • Moderator responses (if provided)

7. User Data Removal Requests

Members may request removal of their stored moderation data by contacting the server owner. Important limitations:

  • The server owner may decline deletion requests for serious actions (bans, harassment, safety violations)
  • Minor actions may be eligible for deletion upon request
  • Deletion requests should be made via the server owner or moderators, not the bot developer
  • No guaranteed timeline for deletion processing

8. GDPR & Data Subject Rights

Users in jurisdictions with privacy laws (e.g., GDPR) have the right to:

  • Access: Request a copy of their stored data
  • Deletion: Request deletion (subject to server owner's retention needs)
  • Portability: Request data in machine-readable format

Submit requests to the server owner or Arctic#0000 (Discord).

9. Third-Party Services

Fox Management integrates with:

  • Twitch API: For streamer notifications (usernames collected for live alerts)
  • Discord API: For all bot functionality (subject to Discord's privacy policy)
  • MongoDB: For data storage (server owner controls credentials)

Each service has its own privacy policy. This bot does not sell or share data with these services beyond necessary API calls.

10. Discord Developer Terms Compliance

Fox Management complies with Discord's Developer Terms of Service:

  • No scraping or harvesting of Discord user data beyond what's necessary for bot operation
  • No storage of user credentials or tokens
  • Moderation data stored only for server management purposes
  • All data handling respects Discord's API rate limits and guidelines
  • Bot does not bypass Discord's security mechanisms or ToS

11. User Consent

By using Fox Management in your server:

  • You acknowledge this privacy policy
  • You consent to data collection as described above
  • You understand moderation actions and context are logged indefinitely
  • You agree the server owner controls data retention and access

Moderators and server members should be informed of this policy.

12. Changes to This Policy

This policy may be updated as Fox Management evolves. Major changes will be communicated to server owners. The "Effective Date" will be updated when changes occur.

13. Contact & Data Requests

For questions, data removal requests, or privacy concerns, contact:

  • Discord: ArcticFox260
  • Server Owner: (primary contact for data access/deletion)

Note: Data requests should first go to your server owner, as they control the database.
