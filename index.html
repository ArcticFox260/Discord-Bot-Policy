Fox Management — Privacy Policy

Effective Date: 10 February 2026

Bot Owner: Arctic

1. What Data We Collect

Fox Management collects the following information when performing moderation actions:

  • User IDs (target member and moderator)
  • Action type (warn, ban, kick, timeout)
  • Reason for the action (if provided)

2. Why We Store This Data

This data is stored to:

  • Maintain moderation history for your server
  • Allow moderators to review past actions
  • Support appeal and dispute resolution

3. Data Retention

Moderation logs are stored unless:

  • Manually deleted by the server owner
  • A user requests removal

4. Who Can Access Data

Data access is limited to:

  • Server owner and administrators
  • Fox Management bot (for logging and appeals)

No data is shared with third parties.

5. Data Removal Requests

Members may request deletion of their moderation data by contacting the server owner. The server owner may:

  • Approve deletion for minor infractions
  • Decline deletion for serious actions where history is needed for server safety

6. Contact

For questions or data removal requests, contact:

  • Discord: ArcticFox260 (or your server owner)
