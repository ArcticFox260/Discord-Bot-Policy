Fox Management — Privacy Policy

Effective: 10 Feb 2026 Updated: 24 June 2026 Owner: Arctic
Application Scope: Fox Management is a custom, private application built solely for use within the Arctic's Lounge Discord server. The bot is intentionally private, cannot be invited to external servers, and exclusively processes data belonging to members interacting within this specific community.

1. What Data We Collect

Fox Management processes server and user data to provide auditing, moderation, and appeal tools. The specific data elements collected and processed include:

  • User Profiles & Identifiers: Discord User IDs, usernames, display names, guild member nicknames (old and new), account creation timestamps, and server join timestamps.
  • Server Metadata & Interactions: Server IDs (Guild IDs), Channel IDs, Role IDs, role assignment changes, channel creation/deletion logs, and server settings adjustments.
  • Activity Logs: Voice channel states (joins, moves, disconnects, server mutes/deafens).
  • Appeals Data: Text submitted via the appeal system, including user-provided appeal reasons, appeal status updates, and moderator review notes.
  • Transient Data (In-Memory Only): Content from deleted or edited messages is processed strictly in-memory to generate immediate staff audit logs within Discord. This specific text data is never saved, cached, or written to our long-term databases.

2. Why We Store This Data

This data is stored and processed to:

  • Maintain a short-term moderation history for the Arctic's Lounge Discord server.
  • Allow authorized server administrators and moderators to review past behavioral actions.
  • Support the server’s appeal, dispute resolution, and security auditing systems.
Prohibited Use Disclaimer: We do not sell, trade, or lease your data. We do not track users across multiple non-affiliated servers, build behavioral user profiles, or use your data to train machine learning or AI models.

3. Data Retention

We implement strict data minimization and do not keep data forever:

  • 90-Day Lifespan: All database logs, moderation history metadata, activity tracking logs, and appeal records are automatically and permanently purged after 90 days via database Time-To-Live (TTL) mechanisms.
  • Automatic Wipe on Leave: When a user leaves the server, the application automatically executes a cleanup script to scrub all linked historical database footprints associated with that user profile.

4. Who Can Access Data

Data access is restricted strictly to:

  • The Server Owner.
  • Authorized server moderators and appeals staff.
  • The Fox Management bot backend infrastructure.

No data is shared with third parties, advertisement brokers, or analytical services.

5. Data Removal Requests

Users retain absolute control over their data footprint. Members may request manual deletion of their stored moderation history or appeal data at any time by contacting the server owner. The server owner may:

  • Approve and manually execute data deletion from the database.

6. Changes to This Policy

This policy may be updated at any time to reflect feature modifications or changes to Discord's Developer Terms. Changes will be reflected by updating the "Updated Date" above.

Fox Management is a third-party bot and is not affiliated with Discord Inc. Use of this bot is subject to Discord's Terms of Service and Community Guidelines. The server owner is responsible for ensuring compliance with applicable laws and Discord's policies.
