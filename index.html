Fox Management — Privacy Policy

Effective Date: 10 February 2026

Bot Owner: Arctic

1. Information Fox Management Collects

Fox Management collects and stores the following information when moderation actions occur:

  • Discord User ID of the member being actioned
  • Discord User ID of the moderator performing the action
  • Action type (e.g., Warn, Ban, Kick, Timeout)
  • Reason for the action (if provided)
  • Timestamp of the action
  • Additional context depending on the command (e.g., duration for timeouts)

2. Purpose of Data Collection

Fox Management stores this information to:

  • Maintain accurate moderation history
  • Allow moderators to review past actions
  • Support appeals or disputes
  • Improve server safety and accountability

This data is not used for advertising, analytics, or profiling.

3. Data Retention

Moderation logs are stored indefinitely unless manually deleted by the server owner or unless a user requests removal (see Section 6).

4. Who Can Access the Data

Access to stored data is limited to:

  • The server owner
  • Authorized moderators
  • Fox Management itself (for lookups and logging)

No data is shared with third parties.

5. How the Data Is Stored

Data is stored in a private database controlled by the server owner. Security measures include:

  • Restricted database access
  • Environment-protected credentials
  • No public endpoints

Fox Management does not store message content unless explicitly logged by a moderation action.

6. User Data Removal

Members may request removal of their stored moderation data by contacting the server owner. Because moderation logs are used for server safety, the server owner may decline deletion requests for serious actions (e.g., bans or harassment cases). For minor actions, deletion may be approved.

7. Changes to This Policy

This policy may be updated as Fox Management evolves. The “Effective Date” will be updated when changes occur.
