Fox Management — Privacy Policy

Effective: 10 Feb 2026 Updated: 6 Sep 2026 Owner: Arctic
Application Scope: Fox Management is a custom, private application built solely for use within the Arctic's Lounge Discord server. The bot is intentionally private, cannot be invited to external servers, and processes data only for members and activity in this community. It is not listed as a public Discord app.

1. What Data We Collect

Fox Management processes Discord API data and related operational data to provide moderation, auditing, appeals, community tools, and go-live alerts. Data we collect or process includes:

  • User profiles & identifiers: Discord user IDs, usernames, display names, nicknames (old and new), avatar URLs (used only to generate welcome images), account creation timestamps, and server join timestamps.
  • Server metadata: Guild IDs, channel IDs, role IDs, role assignment changes, channel create/update/delete events, and server setting changes needed for staff audit logs.
  • Moderation records: Action type (ban, kick, timeout, warn, and related staff actions), target user ID, moderator ID, reason text, optional duration, and timestamps.
  • Voice activity (limited): Staff-initiated voice moves, disconnects, and server mute/deafen events. Routine self-joins to voice channels are not stored in the database.
  • Appeals: Appeal text you submit, action type appealed, status (pending / approved / denied), reviewer identity, review notes, timestamps, and a permanent-denial flag if staff apply one. Only one pending appeal per user is allowed.
  • Temporary voice rooms: Channel ID, creator user ID, channel name, guild ID, creation/last-activity times, and short-lived creation cooldowns. Names are checked against a local profanity list.
  • Counting game: Current count, highest count, last participating user ID, and last audited message ID. Message text is read only to validate numbers.
  • Twitch alerts: Twitch usernames added by staff, stream IDs, live/offline state, and last-live timestamps. If a tracked streamer also shows as live in Discord presence, we may store that Discord user ID with a streaming flag so we do not double-alert.
  • Message content (transient): Message text is processed in memory for profanity checks, the counting channel, and staff delete/edit audit embeds posted in Discord. Delete and edit content is not written to our long-term database (Mongo records store a privacy placeholder instead). Attachments and files are not copied into our database.

2. Discord Privileged Intents

To operate, Fox Management uses Discord privileged intents: Server Members, Presences, and Message Content. These are used only for stated bot features (join/leave and member updates, tracked Twitch presence, moderation logging, profanity checks, and counting).

As of Discord’s 10 June 2026 privileged-intent review changes, apps at or above 10,000 unique users must apply (and reapply annually) to keep this access. This bot is a private, single-server app. If that threshold is ever reached, we will complete Discord’s review with a use case that matches this policy.

3. Why We Process This Data

We process this data only as needed to:

  • Run moderation, staff audit logs, and /hist history for Arctic's Lounge.
  • Operate appeals, including DM notices after a moderation action and staff review buttons.
  • Provide welcome cards, temporary voice rooms, counting, and Twitch go-live alerts.
  • Protect server safety (for example, keeping ban and permanent-appeal-denial records so they are not wiped when someone leaves).
Prohibited uses: We do not sell, license, trade, or lease API data. We do not share it with data brokers or advertising networks. We do not track users across unaffiliated Discord servers, build advertising or eligibility profiles, or use Discord message content or other API data to train machine learning or AI models (including large language models), consistent with Discord’s Developer Policy.

4. Data Retention

We keep data only while it is needed for the features above, then delete it:

  • Moderation history (MongoDB): Automatically deleted after 90 days by a time-to-live index.
  • Appeals: Ordinary appeal records are deleted after 90 days. Records marked permanently denied are kept until staff remove them, so the denial can still be enforced.
  • When you leave the server: We delete ephemeral Twitch presence-alert state tied to your Discord user ID. We do not wipe moderation history or appeals on leave. Ban, kick, timeout, and similar records stay until the 90-day TTL (or longer for permanent appeal denials).
  • Twitch tracker list: Kept until staff remove the username.
  • Counting state: Kept as ongoing game state until reset.
  • Temporary voice: Removed when the room is deleted or cleaned up as empty/inactive.
  • In-memory only: EventSub replay IDs (~10 minutes), recent ban/kick markers (under two minutes), and message text used for filters or Discord staff embeds.

Staff audit embeds posted in Discord remain visible according to that channel’s Discord retention, which is separate from our database TTL.

5. Who Can Access Data & Sharing

Access is limited to:

  • The server owner.
  • Authorized moderators and appeals staff (via Discord roles and staff-only review controls).
  • The Fox Management backend (the bot process and its database).

We share or transmit data only as follows:

  • Discord: The bot uses Discord’s API to run commands, logs, DMs, and server actions. Discord’s own Privacy Policy applies to Discord.
  • Twitch: For staff-tracked channels we call Twitch Helix and EventSub (stream title, game, viewer count, thumbnails, live status). We do not send Discord user IDs, messages, or member lists to Twitch.
  • Hosting / database providers: Infrastructure that stores or runs the bot (service providers), used only to operate Fox Management, with access restricted to the operator.
  • Legal requirement: If required by applicable law or a valid legal process.

We do not share API data with advertisers or analytics brokers. Direct messages from the bot are limited to core functionality (for example, a moderation notice with an appeal button). We do not contact you off Discord using API data.

6. Your Rights & Deletion

Under Discord’s Developer Terms you can ask us to update or delete API data we hold about you. Depending on where you live, you may also have rights under laws such as the Australian Privacy Principles, GDPR / UK GDPR, or CCPA / CPRA (access, correction, deletion, and related rights).

To request access, correction, or deletion, contact ArcticFox260 on Discord (see Contact). We will action deletion promptly unless we must retain a record because:

  • it is still needed for an active enforcement record (for example an unexpired ban or a permanent appeal denial); or
  • applicable law requires us to keep it.

If we stop operating the bot, or Discord requires deletion of API data, we will delete stored API data except where law requires retention.

7. Children

Fox Management is not directed at children. Discord requires users to be at least 13, or older where local law sets a higher digital-consent age. We do not knowingly collect Discord API data about anyone Discord does not permit on the service. If you believe we have, contact us and we will delete it.

8. Security

We use commercially reasonable safeguards, including TLS for database connections, staff-only Discord access for logs and appeal review, HMAC verification of Twitch EventSub webhooks, and binding the webhook listener to localhost behind a reverse proxy. No method of transmission or storage is fully guaranteed. If there is unauthorized access to API data, we will notify affected users and Discord as required by Discord’s Developer Terms and applicable law (including Australia’s Notifiable Data Breaches scheme where it applies).

9. Applicable Terms & Laws

Use of Fox Management is also subject to:

  • Discord Terms of Service and Community Guidelines
  • Discord Developer Terms of Service (effective 8 July 2024)
  • Discord Developer Policy

We handle personal information in line with the Australian Privacy Act 1988 (Cth) as amended, including by the Privacy and Other Legislation Amendment Act 2024 (Australian Privacy Principles, data-security and destruction expectations, and the Notifiable Data Breaches scheme). Members in other regions may have additional rights under GDPR, UK GDPR, LGPD, CCPA, or CPRA; Discord’s Developer Terms require us to respect those frameworks where they apply.

As of this update, Australia’s further Privacy Amendment (Personal Data Protection) Bill 2026 is still an exposure draft (consultation through mid-September 2026) and is not yet law. If it is enacted, we will review this policy and our retention/deletion practices against the new rules.
