Fox Management — Privacy Policy

Effective: 10 Feb 2026 Updated: 6 Sep 2026 Owner: Arctic
Application Scope: Fox Management is a custom, private application built solely for use within the Arctic's Lounge Discord server. The bot is intentionally private, cannot be invited to external servers, and exclusively processes data belonging to members interacting within this specific community.

1. What Data We Collect

Fox Management processes server and user data to provide auditing, moderation, and appeal tools. The specific data elements collected and processed include:

  • User Profiles & Identifiers: Discord User IDs, usernames, display names, guild member nicknames (old and new), account creation timestamps, and server join timestamps. Avatars are used for welcome cards and are not stored in the database.
  • Server Metadata & Interactions: Server IDs (Guild IDs), Channel IDs, Role IDs, role assignment changes, channel creation/deletion logs, and server settings adjustments.
  • Moderation Records: Action type (ban, kick, timeout, warn, and related staff actions), target user ID, moderator ID, reason, duration, and timestamps.
  • Voice Activity: Disconnects, staff-initiated moves, and server mute/deafen events. Self-joins are not stored.
  • Appeals Data: Text submitted via the appeal system, including user-provided appeal reasons, appeal status updates, moderator review notes, and permanent-denial status where applied.
  • Temporary Voice: Channel ID, creator ID, channel name, guild ID, and activity timestamps.
  • Counting: Current count, highest count, and last user ID.
  • Twitch Alerts: Tracked Twitch usernames, stream IDs, live status, stream title, game, viewer count, and thumbnails. Discord user IDs when a member is streaming a tracked channel.
  • Transient Data (In-Memory Only): Content from deleted or edited messages is processed strictly in-memory to generate immediate staff audit logs within Discord. This specific text data is never saved, cached, or written to our long-term databases. Message content is also read in memory for profanity filtering and the counting channel. Attachments are not stored.

The bot uses Discord's Server Members, Presences, and Message Content intents for the features above.

2. Why We Store This Data

This data is stored and processed to:

  • Maintain a short-term moderation history for the Arctic's Lounge Discord server.
  • Allow authorized server administrators and moderators to review past behavioral actions.
  • Support the server's appeal, dispute resolution, and security auditing systems.
  • Run welcome cards, temporary voice rooms, counting, and Twitch go-live alerts.
Prohibited Use Disclaimer: We do not sell, trade, or lease your data. We do not track users across multiple non-affiliated servers, build behavioral user profiles, or use your data to train machine learning or AI models.

3. Data Retention

We implement strict data minimization and do not keep data forever:

  • 90-Day Lifespan: Moderation history and most appeal records are automatically purged after 90 days.
  • Permanent appeal denials: Kept until staff remove them.
  • When a user leaves: Streaming status for that user is deleted. Moderation history and appeals are kept until they expire as above.
  • Twitch tracker list: Kept until staff remove the username.
  • Counting: Kept until the count is reset.
  • Temporary voice: Removed when the room is deleted.

Staff logs posted in Discord stay in that channel until they are deleted there. That is separate from our database.

4. Who Can Access Data

Data access is restricted strictly to:

  • The Server Owner.
  • Authorized server moderators and appeals staff.
  • The Fox Management bot backend infrastructure.

The bot uses Discord's API. Twitch go-live alerts use Twitch's API for channels staff have added. Hosting and database providers store the data we keep. We do not send Discord user IDs, messages, or member lists to Twitch.

We do not share data with advertisement brokers or analytical services. The bot may DM a user after a moderation action so they can submit an appeal. We do not contact users outside Discord.

5. Data Removal Requests

Members may request deletion of their stored moderation history or appeal data at any time by contacting the server owner. We will delete it except where:

  • it is needed for an active ban or a permanent appeal denial; or
  • the law requires us to keep it.

If the bot is shut down, stored data will be deleted except where the law requires us to keep it.

This policy may be updated at any time to reflect feature modifications or changes to Discord's Developer Terms. Changes will be reflected by updating the "Updated Date" above.
